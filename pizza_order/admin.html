Coupons

Customers type the code on the order page. Rules for every coupon: requires a purchase of at least $5.00, only one coupon per order, and each coupon can be used once. A free side or drink coupon makes the lowest-priced matching item in the order free. "Used" is tracked in the browser the order was placed in.
